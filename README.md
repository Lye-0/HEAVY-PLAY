# HEAVY / PLAY

**A beautiful mess.** ネジ、ナット、ワッシャー、ボルト、工具。金属部品の山を、つかんで、投げて、崩すための3Dプレイグラウンドです。

## すぐに遊ぶ

ZIPを**すべて展開してから**、`index.html` をブラウザで開いてください。HTML・CSS・JavaScriptは別ファイルです。ビルド済みのJavaScriptを同梱しているため、閲覧だけならNode.js、npm install、インターネット接続は必要ありません。

必要なのはWebGL 2が使えるブラウザです。グラフィック処理を利用できない環境では、説明付きのエラー画面になります。ブラウザ内のファイルプレビュー機能によってはスクリプトを実行できないため、その場合は通常のブラウザで開くか、下のローカルサーバーを使用してください。

ローカルサーバーで開く場合は、このフォルダで次を実行します。

```sh
npm start
```

表示される `http://127.0.0.1:5173` を開いてください。起動スクリプトはNode.jsの標準機能のみを使用します。ポートを変更する場合、PowerShellでは次のように指定できます。

```powershell
$env:PORT = '5174'
npm start
```

## 遊び方

| 操作 | 内容 | キー |
| --- | --- | --- |
| つかむ | 部品をドラッグ。勢いをつけて離すと投げられます。短くタップすると軽く弾きます。 | G |
| 衝撃 | 押し続けて衝撃をため、離すと周囲の部品が吹き飛びます。 | B |
| 磁石 | 押し続けると周囲の部品を引き寄せます。そのまま移動でき、離すと落ちます。 | M |
| 視点 | ドラッグで回転。ホイールでズームします。 | O |
| 一気に散らす | 山全体に大きな衝撃を与えます。 | X |
| もう少し足す | 上から90個の部品を追加します。全体の上限は2,600個です。 | P |
| 積み直す | 追加した部品を取り除き、元の山を再構成します。 | R |
| スローモーション | 物理時間を0.25倍にします。 | S |
| 一時停止・再生 | 部品の動きを止めます。停止中も視点は操作できます。 | Space |
| 操作ガイド | 操作説明を開きます。 | H |
| 鑑賞表示 | 見出しなどの装飾UIを隠します。もう一度押すかEscで戻ります。 | F |

空いている場所でのドラッグ、右ボタン・中ボタン（ホイール）を押しながらのドラッグ、Shift＋ドラッグでも視点を回せます。**スマートフォンは1本指で部品を操作、2本指で回転・ピンチでズーム**します。

音は初期状態ではオフです。右上の音ボタンでオンにすると、衝突に応じて合成した金属音が鳴ります。BGMではありません。

## 部品と質感

14種類を用意しています。六角ボルト、皿ネジ、六角ナット、平ワッシャー、スプリングワッシャー、六角穴付きボルト、歯車、ベアリング、圧縮ばね、スパナ、六角レンチ、ソケット、金属ドライバー、丸頭リベットです。

銀色の鋼、亜鉛色、真鍮色、黒染め、チタン色、銅色を混ぜています。形状・色・寸法・重量パラメーターはこの作品のための表現であり、実在する規格部品の寸法や材料特性を保証するものではありません。

## 描画品質

| 設定 | 部品数 | 最大描画倍率 | シャドウマップ |
| --- | ---: | ---: | ---: |
| 軽量 | 650 | 1× | 1024 |
| 標準 | 1,200 | 1.5× | 2048 |
| 高精細 | 2,000 | 2× | 2048 |

**PC・スマートフォンともに、初回は標準です。** 重い場合は右上の設定から軽量を選んでください。品質の切り替えで山を作り直します。画面の描画倍率は端末の実際の倍率も上限にします。

品質、音量、自動回転の設定は、利用できる場合のみブラウザのローカルストレージに保存します。音声は次回も自動では開始しません。OSの「視差効果を減らす」に相当する設定を検出した場合、初回の自動回転と再構成の移動アニメーションを抑えます。

### 編集と再ビルド

HTMLとCSSは直接編集すると反映されます。JavaScriptを変更する場合は、`js/app.bundle.js` ではなく元のモジュールを編集し、その後で次を実行してください。

```sh
npm run build:preview
npm test
```

`app.bundle.js` と `snapshots.js` が更新され、**このフォルダの1つ上**に `HEAVY-PLAY-preview.html` が作られます。この単一ファイルは共有用プレビューです。通常のサイトは引き続きHTML・CSS・JavaScriptが分離した構成で動作します。

開始時の配置から作り直す場合のみ、次を実行します。

```sh
node scripts/settle.mjs 650 240
node scripts/settle.mjs 1200 240
node scripts/settle.mjs 2000 270
node scripts/satellites.mjs
npm run build:preview
```

## 実装上の特徴と制約

WebGL 2、Web Audio、標準JavaScriptだけで動きます。外部ライブラリ、CDN、画像素材、外部フォント、APIキー、ネットワークからのモデル取得は使用していません。

部品は画像ではなく立体メッシュです。穴・ねじ山・ばねも形状として生成しています。大量の部品を種類ごとにインスタンス描画し、影、手続き的なスタジオ照明の反射、金属の粗さを組み合わせています。ポインターによる選択は、表示メッシュとの三角形交差判定です。

物理演算は、カプセル形状を中心とした**近似衝突**です。部品ごとの質量パラメーター、回転、摩擦、反発、スリープを持ちますが、ネジの溝同士のかみ合い、穴を通り抜ける精密衝突、ばねの弾性変形までは計算していません。磁石は遊びのために真鍮色や銅色の部品にも作用します。工学解析用ではありません。

WebGLを利用できないプレビュー環境では3D表示できません。全画面表示はブラウザが許可する場合にだけ利用できます。端末によって速度や音声出力は異なり、すべての機種で同じフレームレートを保証するものではありません。

## 公開する場合

`index.html`、`css/`、`js/` の位置関係を保って静的ファイルとして配置できます。実行時には `index.html`、`css/style.css`、`js/app.bundle.js` を読み込みます。初期配置もビルド済みJavaScriptに含まれるため、サーバー側の処理やデータベースは不要です。
