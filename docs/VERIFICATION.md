# 検証結果

作成・検証日：2026-09-06

## 自動テスト

`npm test` による43件のテストがすべて成功しています。乱数の再現性、全14種類の形状データ、各品質の初期配置、剛体の落下と接触、衝撃・引力・ドラッグ、極端な運動後の有限値、分離ファイル構造、外部依存の不在、ローカルサーバーの応答、同梱した衝突音データと元素材の対応、部品同士と床への衝突通知を検証しています。

## ブラウザ検証

ChromiumとMesaのソフトウェアWebGL 2環境で、37項目を確認しています。詳細は `browser-checks.json` を参照してください。

初期表示と実際の継続アニメーションの動作確認に加え、操作の再現性を確保するため、操作テストでは描画と物理のフレームを決定的に進めています。画面キャプチャは実際のWebGLシェーダー・メッシュを描画したものです。

確認内容は、1,200個の初期表示、650・2,000個への品質変更、WebGLエラーの不在、停止・スロー、操作説明、ユーザー操作からの音声開始・ミュート、メッシュ選択、つかむ・投げる、衝撃、磁石、90個追加、積み直し、カメラ回転、ズーム、キーボード操作などです。

スマートフォン向けは390×844のブラウザ表示と、ブラウザの実際のタッチイベントを使って1本指・2本指・ピンチ操作を検証しています。実機のiPhone・AndroidやSafariでの検証ではありません。

## 検証の範囲

この実行環境ではブラウザからローカルHTTP URLへの移動が制限されるため、ブラウザ検証は配布コードと同じCSS・JavaScriptを埋め込んだ共有用HTMLを読み込んで実施しました。ローカルHTTPサーバーは別途、Node.jsのHTTPテストで検証しています。

音声について確認できたのは、ユーザー操作でAudioContextが開始し、同梱した金属衝突音の再生経路が生成され、オン・オフが機能することです。人による実機スピーカーでの聴感評価は行っていません。

全画面表示、端末固有のGPU性能、OSの音量・消音スイッチ、チャット側のプレビュー制約は、実行先に依存します。すべての端末での互換性や一定のフレームレートを保証するものではありません。
